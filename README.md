# Plan_Filler 📚

A Streamlit web application that helps teachers automatically fill weekly lesson plan templates using JSON data.

## ✨ Features
- **JSON-based input**: Paste or upload lesson plan data in JSON format
- **Word document generation**: Automatically fills school templates
- **Custom templates**: Use standard or upload custom school templates
- **User-friendly interface**: No coding experience required
- **Sample data**: Pre-filled examples to understand the format

## 🚀 Quick Start

### Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/Plan_Filler.git
cd Plan_Filler

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run lesson_plan_generator.py
